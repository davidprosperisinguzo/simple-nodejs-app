01 / CONTEXT

What this is

This Node.js app is deployed automatically by GitHub Actions to AWS. It is part of a DevOps class assignment exploring a practical, repeatable path from source code to a running service.

02 / DELIVERY

The pipeline

  1. 01

    Test

    Install dependencies and verify app behavior.

  2. 02

    Build

    Package the app into a portable Docker image.

  3. 03

    Push to ECR

    Publish the versioned image to Amazon ECR.

  4. 04

    Deploy to EC2

    Pull and run the verified image on the server.
